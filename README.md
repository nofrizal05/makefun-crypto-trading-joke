## What this is

One original one-line joke about crypto trading, written for the Laugh Track: The Crypto Trading Joke Contest on make.fun.

## Run it

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
